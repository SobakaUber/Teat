# Container Dashboard 🛰️

Лёгкий дашборд для Docker в киберпанк-стиле. Показывает все контейнеры на
сервере: статус каждого + кнопку для перехода к нему (по опубликованному порту).
Всё работает в локальной сети, без авторизации.

![cyberpunk dashboard](docs/preview.png)

## Как это работает

- **Бэкенд** (`app.py`, Flask) монтирует Docker-сокет в режиме чтения и отдаёт
  список контейнеров со статусами через `/api/containers`.
- **Фронтенд** (одна страница) опрашивает API раз в 5 секунд и рисует плитки.
- Ссылка «Открыть» строится автоматически: `http://<IP сервера>:<порт>`, где
  IP берётся из адреса, по которому открыт сам дашборд. Отдельно прописывать
  IP не нужно.

## Запуск

```bash
docker compose up -d --build
```

Откройте `http://<IP-сервера>:8910` с любого устройства в локальной сети
(телефон, планшет, ноут). На iPhone можно добавить страницу на домашний экран
(Поделиться → «На экран Домой») — будет как нативное приложение.

Остановить:

```bash
docker compose down
```

## Настройка через Docker-лейблы (необязательно)

По умолчанию показываются все контейнеры, а ссылка строится из первого
опубликованного порта. Поведение можно тонко настроить лейблами на ваших
контейнерах:

| Лейбл              | Что делает                                              |
|--------------------|---------------------------------------------------------|
| `dashboard.name`   | Отображаемое имя (по умолчанию — имя контейнера)         |
| `dashboard.icon`   | Эмодзи/символ на плитке, напр. `🗄️`                      |
| `dashboard.port`   | Какой порт использовать для ссылки (если их несколько)   |
| `dashboard.url`    | Полная ссылка вручную (переопределяет авто-определение)  |
| `dashboard.group`  | Название группы/категории                               |
| `dashboard.hide`   | `true` — скрыть контейнер из дашборда                    |

Пример в `docker-compose.yml` вашего сервиса:

```yaml
services:
  myapp:
    image: myapp
    ports:
      - "8080:80"
    labels:
      - "dashboard.name=Моё приложение"
      - "dashboard.icon=🚀"
```

## Цвета статусов

- 🟢 зелёный — `running`
- 🔴 красный — `exited` / `dead` / `created`
- 🟡 жёлтый — `paused` / `restarting`

Бейдж healthcheck (`healthy` / `unhealthy` / `starting`) показывается, если у
контейнера настроен HEALTHCHECK.

## Настройки окружения

| Переменная     | По умолчанию | Описание                                  |
|----------------|--------------|-------------------------------------------|
| `PORT`         | `8910`       | Порт, на котором слушает дашборд           |
| `LINK_SCHEME`  | `http`       | Схема для авто-ссылок (`http` / `https`)   |
